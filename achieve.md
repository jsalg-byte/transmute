Yes. That gives you a perfect third progression layer:

- **Rank** measures public standing.
- **Arcana** records meaningful personal transformation.
- **The Cabinet** holds strange, funny, collectible achievements.

I would call it **The Cabinet of Curiosities**, or simply **The Cabinet** in navigation.

# The Cabinet

Each achievement unlocks an illustrated alchemical object, creature, ingredient, or failed experiment. The user can browse them in a gallery like museum specimens.

```text
THE CABINET

18 / 72 specimens recovered
4 vessels
6 materials
3 creatures
2 celestial seals
3 anomalies
```

Each collectible could show:

```text
THE IMPATIENT ALEMBIC

Complete a session before the rest timer
finishes five times.

Recovered July 24, 2026

“Heat applied with questionable patience.”
```

These should **not affect rank** and should not compete with the seriousness of the Arcana. They exist for surprise, humor, collecting, and personality.

## Visual categories

### Vessels

Alembics, crucibles, retorts, furnaces, flasks, mortars, scales.

### Materials

Salt, sulfur, mercury, lead, cinnabar, vitriol, ash, strange crystals.

### Creatures

Raven, salamander, lion, toad, serpent, phoenix, homunculus.

### Celestial objects

Sun, moon, eclipses, planetary seals, constellations.

### Anomalies

Exploded flasks, bent spoons, suspicious sludge, smoking shoes, failed stones, animated dumbbells.

The anomalies are where the funniest achievements should live.

# Collection presentation

I would avoid Xbox-style square badges. Make each unlock look like a page from an illustrated alchemical catalogue.

Each specimen gets:

- a large engraved illustration
- catalogue number
- achievement name
- category
- unlock date
- short condition
- humorous inscription
- rarity or secrecy status

For example:

```text
SPECIMEN 031
ANOMALY

THE FINAL FINAL SET

Add another set after declaring an
exercise complete.

“This was reportedly the last one.”
```

## Rarity

Rarity should describe how unusual the condition is, not award more points.

```text
COMMON      Found naturally during normal use
CURIOUS     Requires a recognizable pattern
RARE        Requires long-term or unusual behavior
SECRET      Requirement hidden until discovered
```

You could visually distinguish them without bright game colors:

- Common: graphite
- Curious: muted blue-gray
- Rare: aged gold
- Secret: oxblood or black foil

# The gallery should evolve

Rather than showing a dead grid of icons, arrange the Cabinet like a strange laboratory shelf:

- empty silhouettes for known specimens
- question marks or sealed drawers for secret specimens
- vessels grouped together
- creatures mounted like old natural-history plates
- materials shown in jars
- anomalies kept in cracked or irregular frames

Users could select three favorites to display on their profile as their **Cabinet Shelf**.

```text
JON’S CABINET

The Accidental Stone
Mercury Retrograde
The Final Final Set
```

That gives them something funny and personal to show without weakening their serious Arcana achievements.

# Recommended implementation model

```ts
type CabinetAchievement = {
  id: string;
  version: number;
  name: string;
  category: "vessel" | "material" | "creature" | "celestial" | "anomaly";
  rarity: "common" | "curious" | "rare" | "secret";
  description: string;
  flavorText: string;
  imageKey: string;
  isSecret: boolean;
  evaluationType: "event" | "aggregate" | "pattern";
  rule: AchievementRule;
};
```

Store every unlock separately:

```ts
type UserCabinetUnlock = {
  achievementId: string;
  achievementVersion: number;
  unlockedAt: Date;
  triggeringEventIds: string[];
  evidenceSnapshot: Record<string, unknown>;
};
```

The evidence snapshot lets the card say exactly what happened:

```text
THE SMALLest STONE

Bench Press increased from
185 lb × 5 to 185 lb × 6.

Recovered July 24, 2026
```

The combination becomes very strong:

> **Rank shows where you stand.**
> **Arcana shows how you changed.**
> **The Cabinet remembers everything strange that happened along the way.**

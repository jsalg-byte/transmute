# Arcana asset record

The Arcana collection intentionally uses original geometric UI treatments and
typography rather than imported Tarot-card artwork. No third-party SVG is
bundled for this release.

Research sources reviewed before that decision:

- Wikimedia Commons, [Alchemical symbols](https://commons.wikimedia.org/wiki/Alchemical_symbols)
- Wikimedia Commons, [Vectorized Major Arcana](https://commons.wikimedia.org/wiki/Category:Vectorized_major_arcana)

The Vectorized Major Arcana category contains full Tarot-card imagery and may
include licenses unsuitable for app bundling, so it is not imported. Before a
future Commons symbol is added, its individual file page must be recorded here
with the direct URL, author, license, and required attribution. Only public
domain or CC0 files are eligible; CC BY-SA files and any full Tarot artwork are
excluded.
